The hardware, software and services I use day to day, at work and on my own products. Nothing aspirational — if it is listed here, it is in use.

## Hardware

- 14" MacBook Pro (M1, 2021)
- 24" Dell U2415
- Logitech MX Keys Mini for Mac
- Logitech MX Master 3
- Anker PowerExpand 8-in-1
- Logitech Brio 4K webcam
- Aputure MC

## Editor and terminal

- **Editor**: Cursor for most work, VS Code when I want something plain
- **Agentic coding**: Claude Code, running most of the day
- **Terminal**: iTerm2 with zsh and Oh My Zsh

## Building

- TypeScript, React and React Native
- Next.js and Astro
- Node.js and Postgres
- Tailwind CSS
- Storybook for component work

## Running things

- Cloudflare at the edge
- Hetzner for the machines I own
- Vercel where it fits
- GitHub Actions for anything that should happen without me
- PostHog for product analytics
- Stripe for payments

## AI workflow

- Claude and Claude Code for planning, implementation, review and debugging
- Local models for data processing that should stay on my own hardware
- Long-running agents for operations: ingestion health, content triage, payments, dependency updates and reporting across studenti.rs and TenderLift
- Assistants wired into Slack, WhatsApp and Telegram, so the ops loop reaches me where I already am

The point is not the tool list. It is that research, implementation, review and operations can run in parallel, and that every one of those loops still ends with a decision I own.
